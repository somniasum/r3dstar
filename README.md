## Installation

```
git clone https://github.com/somniasum/r3dstar
cd r3dstar
chmod +x install.sh && ./install.sh --all
```

## Keybinds 

Use `Super + /` to open up the keybind list.

### Apps and tools

| Keys                        | Action                                                |
|-----------------------------|-------------------------------------------------------|
| Super+/                     | keybind cheat sheet                                   |
| Super+Return                | terminal                                              |
| Super+w                     | browser                                               |
| Super+d                     | app launcher                                          |
| Super+Shift+d               | run any command from `$PATH`                          |
| Super+\`                    | scratchpad terminal (press again to hide)             |
| Super+n                     | scratchpad notes (current CTF box, or `~/notes.md`)   |
| Super+c                     | scratchpad hex/endian REPL                            |
| Super+v                     | clipboard history                                     |
| Super+Shift+v               | wipe clipboard history                                |
| Super+Shift+i               | copy your VPN IP (LHOST)                              |
| Super+Ctrl+l                | lock screen                                           |
| Super+Escape                | power menu (lock, logout, suspend, reboot, shutdown)  |

### Screenshots

| Keys                        | Action                                                |
|-----------------------------|-------------------------------------------------------|
| Print / Super+s             | select an area (copied to clipboard and saved)        |
| Shift+Print / Super+Shift+s | full screen                                           |
| Super+Print                 | focused window                                        |
| Super+Shift+o               | OCR: select text on screen, it lands in the clipboard |

### Windows

| Keys                        | Action                                                |
|-----------------------------|-------------------------------------------------------|
| Super+q                     | close window                                          |
| Super+Shift+q               | quit Hyprland                                         |
| Super+j / k                 | focus next / previous                                 |
| Super+Shift+j / k           | move the window down / up the stack                   |
| Super+h / l                 | shrink / grow master area                             |
| Super+i / o                 | more / fewer windows in master                        |
| Super+Space                 | promote window to master                              |
| Super+Shift+Space           | toggle floating                                       |
| Super+p                     | pin a floating window to every workspace              |
| Super+m                     | monocle (maximize, keeps the bar)                     |
| Super+f                     | real fullscreen                                       |
| Super+1-9, Super+Shift+1-9  | go to / move window to workspace                      |
| Super+Tab                   | previous workspace                                    |
| Super+drag                  | left = move, right = resize                           |

### System

| Keys                        | Action                                                |
|-----------------------------|-------------------------------------------------------|
| Super+F10                   | game mode on / off                                    |
| Super+b                     | hide / show the bar                                   |
| Super+Shift+r               | reload the config                                     |
| Super+F1 / F2 / F3          | mute / volume down / volume up                        |
| Super+F4                    | mute microphone                                       |
| Super+F5 / F6 / F7          | previous / play-pause / next track                    |
